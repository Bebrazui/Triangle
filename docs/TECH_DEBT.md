# Технический долг TriangleSettings

Документ фиксирует места, где интерфейс настроек ещё не подключён к реальной
системной логике. Обновляется по мере закрытия пунктов.

## Закрыто (реальные системные данные)

- `isCastAvailable()` больше не возвращает `true`: опрашивает маршруты
  `MediaRouter` и отбирает нелокальные приёмники.
- Превью обоев показывает текущее время и дату (обновление раз в 30 секунд,
  формат 12/24ч и локаль берутся из системы).
- «О телефоне»: SELinux (`/sys/fs/selinux/enforce` + `ro.boot.selinux`),
  ABI (`Build.SUPPORTED_ABIS`), Treble (`ro.treble.enabled`), версия
  приложения (`PackageManager`), тип сборки (`Build.TAGS`).
- Версии прошивки в «Обновлении ПО», «О телефоне» и «Хранилище» берутся из
  `Build.VERSION.RELEASE`, `Build.DISPLAY` и `versionName`, а не из литералов.
- Сопряжённые Bluetooth-устройства: тап открывает диалог с реальными данными
  (состояние, класс, MAC, батарея при наличии).
- «Печать», «Трансляция (Cast)», «Android Auto» показываются только если
  система реально может обработать интент (проверка `resolveActivity`) или
  приложение установлено; иначе строка скрыта.

## Осталось (осознанно не закрыто в этом проходе)

| Экран | Проблема | Статус |
|---|---|---|
| Обновление ПО | «Проверить обновления» — `delay(1200)` и фиксированный результат, нет сети | **Блокер**: нет URL/формата OTA-манифеста |
| Точка доступа | Wi-Fi AP — статичная строка; USB/BT-модем пишут несуществующие ключи `Settings.Secure` и не включают тетеринг | Требуется `TetheringManager` + конфиг AP |
| VPN | Профиль сохраняется, «подключение» — только Toast | **Блокер**: нет VPN-клиента / IKEv2-стека |
| Root Provider | Выбор ни на что не влияет | **Блокер**: переключение требует перепрошивки и перезагрузки |
| NFC | Тумблер меняет только локальное состояние, `setNfc` отсутствует | Нужно привилегированное разрешение `NFC_PRIVILEGED` или root |
| История уведомлений | Всегда пустой список | Нужен `NotificationListenerService` и согласие пользователя |
| Bluetooth-сопряжение | Нет сканирования, только текст | Нужен `BluetoothLeScanner` + `startDiscovery` |
| Не беспокоить | Расписание и исключения — статичные строки | Нужны `AutomaticZenRule` |
| Обои и стиль | «Тематические иконки» и «Сетка» меняют только локальное состояние | Нужен общий контракт с лаунчером |
| Хранилище | Разбивка «Приложения/Медиа/Загрузки» = 50/30/10 % от занятого | Нужен `StorageStatsManager` + `MediaStore` |
| Расход батареи | Проценты = доля экранного времени × 38 % | Нужен `BatteryStats` / парсинг `dumpsys batterystats` |
| Каналы уведомлений | Список реальный, но не переключается | Нужен `INotificationManager` через рефлексию |
| Аккаунт на главном экране | Toast «Triangle OS Cloud» | **Блокер**: нет бэкенда |
