# Legacy scripts

Одноразовые скрипты, использовавшиеся при отладке прошивки и приложений
(правка XML/JSON настроек, эксперименты с shared UID, live-патчи SELinux,
regex-правки исходников на месте).

**Не использовать.** Оставлены только как история: большинство из них
редактирует файлы по жёстко заданным путям, содержит серийные номера
устройств или устаревшие предположения о структуре проекта.

Актуальные утилиты лежат в `tools/`.
